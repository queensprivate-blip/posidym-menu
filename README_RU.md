# Посидым Lounge — QR-меню

Версия 0.2.

## Что входит

- стартовая страница;
- раздел «Бар»;
- раздел «Кальяны»;
- отдельные страницы категорий;
- карточки позиций и цен;
- раздел «Акции и правила»;
- мобильная адаптация.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Сейчас меню использует демонстрационные данные из `src/main.js`. Supabase и админская панель будут подключены отдельным обновлением после утверждения структуры внутренних страниц.
