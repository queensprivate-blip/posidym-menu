# Посидым Lounge — QR-меню v0.1

Первая отдельная визуальная версия на Vite и обычном JavaScript.

Запуск: `npm install`, затем `npm run dev`.
Сборка: `npm run build`.

В этой версии: новая стартовая страница, фон заведения, логотип, разделы «Бар», «Кальяны», «Акции и правила», мобильная адаптация и временные данные. Supabase и полноценная админка подключаются следующим этапом.
