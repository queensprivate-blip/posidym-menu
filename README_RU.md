# Посидым Menu v0.6

Мобильное QR-меню кальянной «Посидым Lounge».

## Изменения v0.6

- логотип на стартовой странице открывает информацию о заведении;
- контакты убраны из постоянного нижнего блока;
- возвращена реальная фотография интерьера без дорисованных диванов;
- фон затемняется и тонируется средствами CSS;
- карточки и внутренние страницы стали темнее, тоньше и спокойнее;
- сохранены разделы «Бар», «Кальяны», «Акции и правила».

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```


## v0.6
- Новый обработанный фон с кальяном и встроенным интерьерным логотипом.
- Отдельный прозрачный логотип расположен сверху и открывает информацию о заведении.
- Более мягкое затемнение и премиальная изумрудно-золотая цветокоррекция.


## Изменения v0.6
- главный экран разделён на верхнюю треть для логотипа и нижние две трети для меню;
- используется динамическая высота viewport для iOS и Android;
- три карточки равномерно распределены и сохраняют симметрию на разных экранах.


## Версия 0.7

Раздел «Кальяны» переработан в горизонтальную фотокарусель без подпунктов и цифровых номеров. Добавлены 6 позиций с утверждёнными ценами, свайп, scroll-snap и компактные индикаторы.
