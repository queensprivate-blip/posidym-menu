# Посидым Menu v0.8

Мобильное QR-меню кальянной «Посидым Lounge» на Vite и обычном JavaScript.

## Изменения v0.8

- из предоставленного сохранённого меню перенесены 125 позиций без раздела «Кальяны»;
- сохранены исходные категории, названия, описания, объёмы и цены;
- добавлены 22 категории бара и кухни;
- перенесена акция «Скидка в день рождения»;
- извлечены и оптимизированы 88 встроенных фотографий;
- фотографии выводятся в карточках позиций, если они действительно были сохранены внутри файла;
- раздел «Кальяны» и его карусель оставлены без изменений;
- данные вынесены в `src/menu-data.js`;
- изображения меню находятся в `public/menu-images/`.

## Запуск

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
node --check src/main.js
node --check src/menu-data.js
npm run build
```
